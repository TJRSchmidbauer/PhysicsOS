# Electric Engine

Deterministische Engine der Elektrik-Domäne für PhysicsOS. V1 liefert Hilfsfunktionen
für das Coulomb-Feld und das Potenzial sowie einen analytischen 2D-Löser für geladene Teilchen
in einem globalen homogenen elektrischen Feld. Die Engine gibt nachvollziehbare Größen für Kraft, Beschleunigung,
Potenzial und Energie aus; das Rendering bleibt außerhalb dieses Packages.
